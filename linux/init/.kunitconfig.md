## CONFIG_KUNIT

**Description:**  
Enables KUnit, the in-kernel unit testing framework.

**Purpose:**  
Allows developers to write and run unit tests inside the kernel.

**Behavior:**  
When enabled, test suites can be built into the kernel and executed at boot or runtime.

**Dependencies:**  
None required for normal operation, but used only for testing/debugging.

**Impact:**  
Increases kernel size slightly.  
Not used in production systems.

**Typical Use:**  
Kernel development and validation.

## CONFIG_BLK_DEV_INITRD

**Description:**  
Enables support for initial RAM disk (initrd/initramfs).

**Purpose:**  
Allows the kernel to load a temporary root filesystem into memory during boot.

**Behavior:**  
Kernel can unpack an initramfs archive and execute `/init` as the first userspace process.

**Dependencies:**  
Requires initramfs image passed at boot (via bootloader or QEMU).

**Impact:**  
Essential for custom boot environments and minimal OS setups.

**Typical Use:**  
Early userspace, embedded systems, custom OS bootstrapping.


---

## CONFIG_INITRAMFS_TEST

**Description:**  
Enables test code for initramfs functionality.

**Purpose:**  
Provides internal testing for initramfs handling within the kernel.

**Behavior:**  
Adds test routines related to initramfs loading and validation.

**Dependencies:**  
Used only when testing kernel features.

**Impact:**  
Adds unnecessary code for normal operation.

**Typical Use:**  
Kernel testing and debugging only.
